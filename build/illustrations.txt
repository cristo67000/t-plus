# Les illustrations de T+, et d'où elles viennent.
#
#     python build/verifier_commons.py liste.txt   vérifie des propositions (existence, licence) avant de les ajouter ici
#     python build/illustrer.py                    télécharge, vérifie la licence, convertit en WebP dans img/
#                                                  et écrit build/illustrations.json
#     node build/construire.mjs                    rattache ensuite chaque image à ses articles
#
# Toutes viennent de Wikimedia Commons. illustrer.py n'accepte que le domaine public,
# CC0, CC BY et CC BY-SA ; l'application affiche alors l'auteur et la licence sous
# l'image et au bas de l'article. Tout le reste (NC, ND, droits réservés) est refusé.
#
# ── Une image ───────────────────────────────────────────────────────────────
#
#   = sceau-du-temple             identifiant : le fichier sera img/sceau-du-temple.webp
#   commons: Fichier.jpg          le fichier sur Wikimedia Commons, sans « File: »
#   legende: Le sceau du Temple   ce qu'on lit sous l'image (*italique* permise)
#   credit: Archives nationales   l'auteur, la date, le fonds — la licence s'ajoute seule
#   pour: sceau-du-temple         les articles où elle paraît, en tête, séparés par des virgules
#   largeur: 440                  (facultatif) largeur en pixels, 560 par défaut
#   recadrer: 0.02 0 0.98 1       (facultatif) gauche haut droite bas, en fractions
#
# « % un titre » ouvre un lot : les champs écrits juste après valent pour toutes
# les images suivantes, jusqu'au prochain « % ».
#
# Les portraits des maîtres sont tous imaginaires (aucun portrait contemporain
# n'existe) : la légende le dit.

# ── Les images (écrites par build/assembler_illustrations.py, ne pas retoucher à la main) ──
