# Le choix des illustrations de T+ : une ligne par image.
#
#     article[, article…] | Fichier sur Commons | Légende [| Crédit]
#
# Un quatrième champ, facultatif, remplace le crédit lu sur Commons (« Auteur, année »).
#
# Le premier article reçoit l'image en tête ; les suivants aussi (une même image peut
# servir à plusieurs articles). L'ordre des lignes est l'ordre d'affichage dans un article.
#
#     python build/assembler_illustrations.py   écrit build/illustrations.txt (crédits pris sur Commons)
#     python build/illustrer.py                 télécharge, vérifie la licence, convertit
#
# Toute image passe d'abord par build/verifier_commons.py.
