# Frises de T+ — format des fichiers
#
#   @ identifiant                 une frise
#   nom: …                        son nom court
#   titre: …                      ce qu'elle montre
#   couleur: #rrggbb              teinte de la frise
#   voie: id | Nom                une voie (colonne) ; la première est la voie par défaut
#   % id | Nom | début | fin | #rrggbb      une période ; ses lignes « titre: » et « voie: »
#   titre: …                      s'appliquent aux mandats qui suivent, jusqu'à la période suivante
#   = article | début | fin | Nom affiché | titre | note      un mandat ; « article » est l'identifiant
#                                 d'un article de build/articles/, ou « - » quand il n'y en a pas
#
#   Dates : AAAA, AAAA-MM ou AAAA-MM-JJ ; « ~ » devant = approximatif.
#   Les champs vides héritent : titre de la période, voie courante.
#
# Les dates des maîtres suivent Alain Demurger (Les Templiers, 2005 ; Jacques de Molay, 2007)
# et Malcolm Barber (The New Knighthood, 1994) ; quand elles divergent, la note le dit.
